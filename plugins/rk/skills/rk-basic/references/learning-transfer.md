# 通俗讲解与举一反三

本参考用于把一个软考知识点讲懂，并把一道题变成下一道可练的题。目标是让用户能独立迁移，不只是看懂当前答案。

## 通俗讲解

优先使用「一句话 + 考试说法 + 为什么」的顺序。

- `一句话`：用不超过两句白话说出核心作用。
- `生活类比`：只用于帮助理解，后面必须说明类比的边界。
- `考试说法`：转换成选择题、案例题或论文里会出现的术语。
- `为什么这样`：讲机制或因果，不只背结论。
- `容易误解`：点出一个最容易选错或写偏的地方。
- `检查小题`：给一个 1 分钟能回答的小问题，用来确认是否真懂。

类比不能替代考试答案。讲完类比后，要回到标准术语，例如「缓存穿透」「流水线吞吐率」「一致性补偿」「质量属性刺激」。

## 分层提示

用户说「不会」「卡住了」时，先给提示，不急着给完整答案。

1. `提示 1`：指出题干或关键词，不暴露答案。
2. `提示 2`：给判断公式、分类规则或答题骨架。
3. `完整讲解`：用户答完、追问答案，或明确要看答案时再给。

如果用户正在考前速记、明确要答案，或题目本身是查缺补漏，可以直接回答。

## 举一反三

每次只改一个关键条件，避免一次塞太多变式。

可选变式方式：

- `换条件`：把强一致改成最终一致、把单机改成集群、把读多写少改成写多读少。
- `换问法`：从计算结果改成易错判断，从定义改成适用场景。
- `换场景`：把电商秒杀换成在线教育抢课、政务共享、医疗预约等。

输出时先保留「原题抓手」，再给「变式题」。用户答题前，只给题目和必要提示；用户答完后，比较原题和变式的共性、变化点、答案调整。

## 复盘规则

复盘时区分三种状态：

- `独立答对`：可以进入下一题或提高难度。
- `提示后答对`：记录为半掌握，下次用相同考点换场景再练。
- `看答案才懂`：回到通俗讲解，下一题只改一个条件。
