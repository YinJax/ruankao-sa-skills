## 题干关键词路由

- `高并发、热点、接口被打爆、连接耗尽` -> 限流、缓存、负载均衡、扩容、降级。
- `服务调用失败、雪崩、第三方不稳定` -> 熔断、降级、隔离、超时、重试、监控。
- `服务实例动态变化、地址硬编码、注册信息失效` -> 注册中心、健康检查、服务发现、缓存刷新。
- `缓存与数据库不一致、脏数据、删除失败` -> Cache Aside、先更新库再删缓存、延时双删、异步重试。
- `跨服务写入、订单支付库存` -> 分布式事务、最终一致、TCC、Saga、消息可靠投递。
- `旧 Token 仍可用、越权访问` -> JWT 状态管理、黑名单、短有效期、权限实时校验、审计。
- `恢复时间、故障切换、心跳` -> 可用性、冗余、故障检测、MTTR。
- `响应时间、吞吐量` -> 性能、缓存、并发、减少开销、资源调度。
- `新增需求、模块替换、快速迭代` -> 可修改性、抽象、信息隐藏、低耦合。
