# 数据库系统

## 覆盖范围

对应资料 17-19：数据库理论、数据库设计、事务管理与并发控制。

## 高频考点

### 数据库基础

- 数据库系统由数据库、数据库管理系统、应用程序和数据库管理员等组成。
- 数据模型常见层次模型、网状模型、关系模型、面向对象模型。
- 关系模型核心包括关系、元组、属性、码、外码、完整性约束。
- 三类完整性：实体完整性、参照完整性、用户定义完整性。

### 关系代数与 SQL

- 关系代数常见选择、投影、连接、并、差、笛卡尔积。
- 选择是按行筛选，投影是按列筛选。
- 自然连接会按同名属性自动等值连接，并去掉重复属性。
- SQL 题要注意 `WHERE` 过滤行，`GROUP BY` 分组，`HAVING` 过滤分组。

### 规范化

- 函数依赖是规范化判断基础。
- 1NF 要求属性不可再分。
- 2NF 在 1NF 基础上消除非主属性对候选码的部分依赖。
- 3NF 在 2NF 基础上消除非主属性对候选码的传递依赖。
- BCNF 要求每个非平凡函数依赖的决定因素都是候选码。
- 分解要关注无损连接和保持函数依赖。

### 数据库设计

- 数据库设计常见阶段：需求分析、概念结构设计、逻辑结构设计、物理结构设计、实施、运行维护。
- E-R 图用于概念结构设计，关系模式用于逻辑结构设计。
- 实体转关系，实体属性转字段，联系根据一对一、一对多、多对多转换。
- 多对多联系通常转换为独立关系，并引入双方主码作为外码。

### 事务与并发控制

- 事务 ACID：原子性、一致性、隔离性、持久性。
- 并发问题包括丢失修改、不可重复读、读脏数据、幻读。
- 封锁分共享锁和排他锁。共享锁可并发读，排他锁用于写。
- 两段锁协议要求先加锁后解锁，解锁后不再加锁，可保证冲突可串行化。
- 死锁可通过预防、检测、超时等方式处理。

### 备份与恢复

- 故障类型包括事务故障、系统故障、介质故障。
- 日志用于恢复事务，常见操作包括重做和撤销。
- 检查点用于缩短恢复时间。
- 备份可分完全备份、增量备份、差异备份。

### 分布式数据库与 NoSQL

- 分布式数据库关注分片、复制、透明性和一致性。
- NoSQL 常见类型：键值、文档、列族、图数据库。
- CAP 理论关注一致性、可用性和分区容错性。

## 答题提醒

- 规范化题先找候选码，再判断部分依赖和传递依赖。
- E-R 转关系题先判断联系基数。
- 事务题先找并发异常类型，再对应隔离或封锁策略。
- 恢复题先判断故障类型，再决定撤销还是重做。
