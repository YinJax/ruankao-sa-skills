# 考纲映射与资料索引

## 使用原则

回答时以「软考高级系统架构设计师」考试口径组织内容。不要把资料原文完整复述给用户，优先提炼成考点、公式、判断规则和易错提醒。

## 资料来源说明

本 Skill 基于 30 篇软考系统架构师基础知识 Markdown 笔记提炼，覆盖：

- 01：完整知识体系与核心考点总结
- 02-07：计算机系统基础
- 08-11：操作系统
- 12-16：计算机网络
- 17-19：数据库系统
- 20：知识产权与标准化
- 21-27：软件工程
- 28-30：系统架构设计

需要查原始笔记时，按文件标题中的序号和模块定位，不要一次性读取全部文件。

## 复习建议

1. 先用 `cheatsheet.md` 做模块总览。
2. 刷题时按错题所属模块读取对应 reference。
3. 对公式题，要求用户给出完整题干和选项。
4. 对案例题，先识别知识点，再组织答题关键词。
5. 对不确定或时效性内容，提醒用户核对官方大纲和考试通知。
