# 计算机系统基础

## 覆盖范围

对应资料 02-07：计算机体系结构、存储体系结构、主存编址、磁盘管理与调度、数据传输与控制方式、校验码。

## 高频考点

### 计算机体系结构

- CPU 由运算器、控制器、寄存器组和内部总线组成。
- 指令执行通常按取指、译码、执行、访存、写回理解。
- CISC 指令复杂、长度可变、硬件控制复杂；RISC 指令简单、长度固定、流水线友好。
- Flynn 分类常见为 SISD、SIMD、MISD、MIMD，考试常考并行类型识别。

### 存储体系

- 存储层次按速度从高到低通常是寄存器、Cache、主存、辅存。
- 局部性原理包括时间局部性和空间局部性，是 Cache 和虚拟存储的基础。
- Cache 命中率题常用平均访问时间：`命中率 × Cache 访问时间 + 未命中率 × 主存访问时间`。如果题目说明未命中时先访问 Cache 再访问主存，要把两段时间都算进去。
- 地址映射常见直接映射、全相联映射、组相联映射。直接映射实现简单但冲突多，全相联冲突少但成本高。

### 主存编址

- 存储容量计算常见形式：`容量 = 地址单元数 × 每单元位数`。
- 地址线数量决定可寻址单元数：`2^地址线数`。
- 数据线数量决定一次可传输的数据位数。
- 字节编址和字编址要先看题目单位，常见陷阱是把 bit、Byte、KB、Kbit 混用。

### 磁盘与调度

- 磁盘访问时间通常由寻道时间、旋转延迟和传输时间构成。
- FCFS 简单公平但平均寻道时间可能较大。
- SSTF 优先最近磁道，平均寻道时间较小，但可能导致远端请求饥饿。
- SCAN 像电梯一样单向扫描，兼顾效率和公平性。
- C-SCAN 单向循环扫描，等待时间更均匀。

### 数据传输与控制

- 程序查询方式简单但 CPU 浪费明显。
- 中断方式适合低速 I/O，CPU 利用率较高。
- DMA 适合高速批量数据传输，数据在内存和外设之间直接传送，CPU 只参与初始化和结束处理。
- 流水线总时间常见公式：`一条指令执行时间 + (指令条数 - 1) × 流水线周期`。流水线周期取最长子段时间。
- 加速比：`非流水执行时间 / 流水执行时间`。

### 校验码

- 奇偶校验只能检测奇数位错误，不能可靠纠错。
- CRC 用模 2 除法，常考生成校验码和检测余数。
- 海明码用于纠错，校验位数满足：`2^r >= m + r + 1`，其中 `m` 是数据位数，`r` 是校验位数。
- 海明码出错位置由校验结果组成的二进制数确定。

## 答题提醒

- 看到容量题，先统一单位，再判断按位编址还是按字节编址。
- 看到 Cache 题，先确认未命中时间是否包含 Cache 访问时间。
- 看到流水线题，先找最长阶段作为流水线周期。
- 看到磁盘调度题，先画磁道访问顺序，再算总移动距离。
- 看到校验码题，先判断题目问的是检错能力、纠错能力还是具体编码。
