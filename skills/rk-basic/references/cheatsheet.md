# 考前速记与易混点

## 复习顺序

1. 先扫计算题：主存编址、Cache、流水线、磁盘调度、校验码、子网划分、规范化。
2. 再扫选择题概念：OSI、协议归属、开发模型、UML、测试、维护、架构风格。
3. 最后扫记忆项：知识产权、标准编号、4+1 视图、质量属性。

## 高频公式

| 题型 | 公式或判断 |
|---|---|
| 地址空间 | `2^地址线数` |
| 存储容量 | `地址单元数 × 每单元位数` |
| Cache 平均访问时间 | 按题意区分命中时间和未命中惩罚 |
| 流水线总时间 | `首条完整时间 + (n - 1) × 流水线周期` |
| 流水线周期 | 最慢子段时间 |
| 海明校验位 | `2^r >= m + r + 1` |
| 磁盘访问时间 | 寻道时间 + 旋转延迟 + 传输时间 |
| 子网主机数 | `2^主机位数 - 2`，特殊题按题意处理 |

## 易混对比

| 易混点 | 判断规则 |
|---|---|
| 进程 vs 线程 | 进程偏资源分配，线程偏 CPU 调度 |
| 页式 vs 段式 | 页式物理等长，段式逻辑可变长 |
| TCP vs UDP | 可靠有序选 TCP，实时低开销选 UDP |
| 选择 vs 投影 | 选择筛行，投影筛列 |
| 黑盒 vs 白盒 | 黑盒看功能，白盒看结构 |
| 测试 vs 调试 | 测试发现错误，调试定位和修复错误 |
| 瀑布 vs 原型 | 需求稳定选瀑布，需求不清选原型 |
| 螺旋 vs 增量 | 高风险选螺旋，分批交付选增量 |
| 逻辑视图 vs 进程视图 | 功能对象选逻辑，并发性能选进程 |
| NAS vs SAN | 文件级共享选 NAS，块级高性能选 SAN |

## 一分钟判断

- 看到「风险分析」：优先想到螺旋模型。
- 看到「需求不明确」：优先想到原型模型。
- 看到「分阶段数据处理」：优先想到管道-过滤器。
- 看到「共享数据中心」：优先想到仓库风格。
- 看到「并发、线程、通信」：优先想到 4+1 的进程视图。
- 看到「部署节点、网络拓扑」：优先想到物理视图。
- 看到「功能、对象、类」：优先想到逻辑视图或类图。
- 看到「消息时间顺序」：优先想到顺序图。
- 看到「生命周期状态变化」：优先想到状态图。
- 看到「活动流程」：优先想到活动图。
