# 题目适配判断

Use this reference when deciding whether a project can support a requested topic.

## 可以支持

- 用户项目里有与题干关键词直接相关的场景。
- 用户能说清架构师角色下的决策、实施动作和权衡。
- 至少能形成 3 个可辩护论点。
- 项目结果能被事实、数据、验收或反馈支撑。

## 需要谨慎

- 用户提供的项目事实过少
- 题目要求和项目方向明显不一致
- 只有结果，没有过程
- 只有技术名词，没有决策和权衡
- 项目时间不满足用户要求的近三年约束，或考试年份未确认

## 处理方式

- 能支撑：生成模板，并标出替换位。
- 勉强支撑：生成模板，但把风险写明。
- 不能支撑：先要求补充事实，不硬套。

## 项目-主题覆盖矩阵

输出适配判断时给出简表：

| 题目模块 | 项目事实支撑 | 风险 |
| --- | --- | --- |
| 模块 1 | `[对应事实]` | `[风险或无]` |
| 模块 2 | `[对应事实]` | `[风险或无]` |
| 模块 3 | `[对应事实]` | `[风险或无]` |
