# 素材边界

Use this reference when the user provides历年真题、论文范文、必背材料、模板汇总或转换后的 Markdown。

## 素材分类

- `项目事实`：用户自己的项目时间、背景、目标、角色、约束、架构决策、实施动作、结果数据。
- `题目材料`：历年论文题目、题干要求、选题限制、必须回应的问题。
- `范文材料`：示例论文、必背模板、分类资料、论点展开方式。

## 使用规则

- 项目事实可以进入模板正文，但缺失或不确定处必须写 `[待本人确认]`。
- 题目材料用于拆解义务、限定主题、决定必须替换的位置。
- 范文材料只用于提取分类、论点组织、段落功能和表达节奏。
- 从范文提取的技术、规模、数字、单位、系统名称、个人角色和结果不能写成用户项目事实。

## 范文提取清单

读取范文或必背材料时，只提取：

- 论文主题属于哪个分类。
- 常见论点有哪些，每个论点解决什么问题。
- 每个论点可展开的角度。
- 理论段怎样转入项目实例。
- 哪些段落适合改成考场替换位。

## 风险处理

- 用户项目和范文项目不一致时，以用户项目为准。
- 范文给出很漂亮但用户未提供的成果，改成 `[待本人确认的成果]`。
- 范文使用的统一示例项目只能作为结构样本，不能替换用户自己的项目。
- 当用户只给范文而没有项目事实时，只能输出题目模板骨架和事实访谈问题。
