# 范文结构诊断

Use this reference to diagnose whether a draft reads like an exam essay instead of a generic project summary.

The public `system_architect` essay materials group samples into latest references, true-prompt samples, older samples, and exam technique/template files. Use that organization only as structural evidence. Do not copy sample wording or sample project facts.

## 诊断项

| 维度 | 稳妥表现 | 高风险表现 |
| --- | --- | --- |
| 摘要密度 | 题目、项目、角色、措施、结果齐全 | 只介绍项目背景或只喊主题口号 |
| 题干覆盖 | 正文小标题能对应题目义务 | 小标题是技术清单，和题干动词无关 |
| 项目落地 | 每个论点都有本人动作和实施细节 | 只有理论定义，没有项目动作 |
| 权衡结果 | 写出取舍、问题、验证或效果 | 只写“采用某技术后效果良好” |
| 可答辩性 | 数据、角色、时间、系统边界一致 | 项目事实前后不一或明显泛化 |

## 改写优先级

1. 先补题干没有覆盖的段落。
2. 再把教材式理论改成项目链条：`场景 -> 决策 -> 实施 -> 权衡 -> 结果`。
3. 最后压缩背景和口号。

## 禁止事项

- 不按范文原句润色。
- 不替用户发明项目指标、角色或验收结果。
- 不把训练估分写成官方过线判断。
