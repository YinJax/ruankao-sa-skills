# 软考系统架构师案例题必背知识卡 Skill

这个 Skill 用于背诵软考高级系统架构设计师「案例分析」基础必备专题。目标是每次调用时输出「必答题稳分 + 选做题高频专题」的知识卡，而不是拆解某一道具体题。

## 工作流

1. 先判断用户要的是总览卡、单专题卡、背诵清单还是考前速记。
2. 默认按「必答题稳分专题 -> 选做题高频专题 -> 背诵顺序 -> 使用方法」组织。
3. 每个专题只保留案例题能转成采分点的内容：题干关键词、必背概念、得分句式、易丢分点。
4. 对来源不确定、趋势性或超纲内容，标注为「训练推断」，不要说成官方结论。
5. 用户给出具体案例题、答案草稿或要求估分时，提醒改用 `rk-case-drill`。

## 默认专题地图

### 必答题稳分

- 质量属性：性能、可用性、安全性、可修改性、可靠性、功能性、可变性、互操作性。
- 质量属性场景：刺激源、刺激、环境、制品、响应、响应度量。
- 架构评估：效用树、敏感点、权衡点、风险承担者、场景。
- 架构评估方法：SAAM、ATAM、CBAM，以及基于场景和基于度量的评估思路。
- 架构风格对比：管道-过滤器、仓库、面向对象、基于规则、分层、事件驱动。

### 选做题高频

- UML 与建模：用例图、类图、顺序图、活动图、状态图、DFD。
- 数据库设计：E-R、关系模式、规范化、反规范化、完整性、读写分离、分库分表。
- Redis 与缓存：Cache Aside、穿透、击穿、雪崩、延时双删、异步重试、集群。
- 分布式事务：2PC、TCC、Saga、本地消息表、可靠消息、最终一致、幂等补偿。
- 微服务治理：注册发现、网关、限流、熔断、降级、隔离、链路追踪。
- 负载均衡：轮询、权重、最小连接、一致性哈希、健康检查、弹性扩缩容。
- 安全架构：认证、授权、SSO、OAuth2、JWT、RBAC、ABAC、加密、审计。
- 云原生：容器、Kubernetes、DevOps、弹性伸缩、滚动发布、可观测性。
- 大数据与数据存储：Lambda、Kappa、湖仓一体、NoSQL、对象存储、分布式文件系统。
- DSSA 与架构复用：领域分析、领域设计、领域实现、垂直域、水平域、参考架构。

## 默认输出

### 总览卡

输出：

- `必答题稳分专题`：按优先级列出必背主题和保底分来源。
- `选做题高频专题`：按优先级列出适合选做题准备的主题。
- `背诵顺序`：给出先背什么、后背什么。
- `使用方法`：说明如何从题干关键词映射到专题和得分句。

### 单专题卡

输出：

- `题干关键词`：看到哪些词要想到本专题。
- `必背概念`：只保留案例题会用到的概念。
- `高频问法`：说明、分析、设计、改进、比较分别怎么问。
- `得分句式`：给出考场可直接改写的短句。
- `易丢分点`：指出空泛、答偏、漏闭环、缺权衡的写法。
- `迁移判断`：下次遇到类似题怎么快速识别。

## 答题原则

- 卡片服务于考场作答，不写成百科解释。
- 先背「题干关键词 -> 专题 -> 措施 -> 效果/代价」链路。
- 得分句式必须能贴回题干中的故障、约束、业务目标、质量属性或技术现状。
- 不虚构官方押题、分值细则、技术版本和题干没有给出的业务指标。

## 与其它软考 Skill 的边界

- 具体真题拆解、答案诊断、模拟评分交给 `rk-case-drill` Skill。
- 基础概念、选择题知识点交给 `rk-basic` Skill。
- 论文结构、项目事实和论文评分交给 `rk-essay` Skill。
