# 软考系统架构师案例题必背知识卡 Skill

这个 Skill 用于背诵软考高级系统架构设计师「案例分析」基础必备专题。目标是用 4 个入口完成「今日背、稳分题、新方向、记录」，而不是拆解某一道具体题。

## 工作流

1. 用户只输入 `/rk-case-card` 时，只输出「案例背诵」4 项菜单：`1 今日背`、`2 稳分题`、`3 新方向`、`4 记录`。
2. 支持用户用编号或关键词继续调用，例如 `/rk-case-card 1`、`/rk-case-card 今日背`、`/rk-case-card 新方向`、`/rk-case-card 质量属性`。
3. `今日背` 默认输出 1 张必答稳分卡 + 2 张高频或新方向卡；如果用户提供复习记录，优先安排最近薄弱点。
4. 每张卡只保留能转成采分点的内容：题干关键词、必背概念、得分句式、易丢分点。
5. 用户给出具体案例题、答案草稿、要求出题或估分时，提醒改用 `rk-case-drill`。

## 默认菜单

```text
案例背诵
1. 今日背
2. 稳分题
3. 新方向
4. 记录
```

## 菜单行为

- `今日背`：给出今天要背的 3 张卡，按「稳分 -> 高频 -> 新方向」排序，并附 1 行复习记录模板。
- `稳分题`：列出必答题稳定专题，让用户按编号选择后输出单专题卡。
- `新方向`：按「必看、高频、补充」列出新颖专题，让用户按编号选择后输出转译卡。
- `记录`：查看或追加轻量复习记录；没有外部记忆时，输出可复制的 Markdown 日志行。

## 默认专题地图

### 必答题稳分

- 质量属性：性能、可用性、安全性、可修改性、可靠性、功能性、可变性、互操作性。
- 质量属性场景：刺激源、刺激、环境、制品、响应、响应度量。
- 架构评估：效用树、敏感点、权衡点、风险承担者、场景。
- 架构评估方法：SAAM、ATAM、CBAM，以及基于场景和基于度量的评估思路。
- 架构风格对比：管道-过滤器、仓库、面向对象、基于规则、分层、事件驱动。

### 选做题高频

- UML 与建模：用例图、类图、顺序图、活动图、状态图、DFD。
- 数据库设计：E-R、关系模式、规范化、反规范化、完整性、读写分离、分库分表。
- Redis 与缓存：Cache Aside、穿透、击穿、雪崩、延时双删、异步重试、集群。
- 分布式事务：2PC、TCC、Saga、本地消息表、可靠消息、最终一致、幂等补偿。
- 微服务治理：注册发现、网关、限流、熔断、降级、隔离、链路追踪。
- 负载均衡：轮询、权重、最小连接、一致性哈希、健康检查、弹性扩缩容。
- 安全架构：认证、授权、SSO、OAuth2、JWT、RBAC、ABAC、加密、审计。
- 云原生：容器、Kubernetes、DevOps、弹性伸缩、滚动发布、可观测性。
- 大数据与数据存储：Lambda、Kappa、湖仓一体、NoSQL、对象存储、分布式文件系统。
- DSSA 与架构复用：领域分析、领域设计、领域实现、垂直域、水平域、参考架构。

### 新方向转译

- 必看：AI/大模型平台、端侧 AI/物联网、知识图谱/智能问答、向量数据库/RAG。
- 高频：云原生数据库、Redis 旁路缓存、Elasticsearch 搜索、Serverless。
- 补充：医疗安全/危险驱动分析、边云协同、多模态 AI 测试。

## 默认输出

### 单专题卡

输出：

- `看到这些词`：题干出现哪些词要想到本专题。
- `它其实考什么`：把新名词转译成质量属性、架构风格、数据、治理、安全或建模等老考点。
- `必背概念`：只保留案例题会用到的概念。
- `得分句`：给出考场可直接改写的短句。
- `易丢分`：指出空泛、答偏、漏闭环、缺权衡的写法。

### 记录模板

输出：

```text
- 日期：
  今日背：质量属性 / Redis 缓存 / RAG
  熟练：质量属性
  薄弱：RAG 的题干转译
  明天优先：RAG + 云原生数据库
```

## 答题原则

- 卡片服务于考场作答，不写成百科解释。
- 先背「题干关键词 -> 专题 -> 措施 -> 效果/代价」链路。
- 得分句式必须能贴回题干中的故障、约束、业务目标、质量属性或技术现状。
- 不虚构官方押题、分值细则、技术版本和题干没有给出的业务指标。

## 与其它软考 Skill 的边界

- 具体真题拆解、答案诊断、模拟评分交给 `rk-case-drill` Skill。
- 基础概念、选择题知识点交给 `rk-basic` Skill。
- 论文结构、项目事实和论文评分交给 `rk-essay` Skill。
