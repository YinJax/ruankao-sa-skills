这些是由 15 篇训练 Markdown 提炼出的样本类型索引。使用时只借用题型结构和答题套路，不复制原文。

## 生成同类练习

生成练习题时包含：

1. 一个具体行业背景：电商、金融、在线教育、政务、医疗、物流等。
2. 3-5 个明确问题现象：超时、雪崩、数据不一致、越权、节点故障、扩展困难。
3. 4-5 个分问：原因分析、机制说明、方案设计、技术比较、综合改进。
4. 参考答案只给要点，不给长篇原文。
5. 给出评分点，便于用户自评。

## 变式训练

变式训练一次只改一个变量，并说明「本次只改变」了什么。优先围绕用户刚暴露的薄弱点改题，例如不会写原因、措施、风险、权衡或题干证据。

| 原题抓手 | 变式方向 | 可复用套路 |
|---|---|---|
| 电商高并发 | 改成在线教育抢课 | 限流、熔断、热点缓存、降级 |
| 金融权限 | 改成政务数据共享 | RBAC + ABAC、审计、加密、最小权限 |
| Redis 缓存一致 | 改成商品库存读写 | Cache Aside、延时双删、消息补偿、幂等重试 |
| 服务注册失败 | 改成 Kubernetes 节点异常 | 健康检查、故障转移、扩缩容、可观测 |
| 数据强一致 | 改成最终一致 | 可靠消息、补偿、对账、状态机 |

## 分层提示

用户没作答前，不直接给完整答案。按三层推进：

1. 线索提示：指出题干触发词，例如「超时」「越权」「单点」「强一致」。
2. 答题骨架：给「原因 + 措施 + 效果/代价」或「组件 + 流程 + 保障」。
3. 对照讲解：用户答完或明确要答案后，再给评分点和标准化表达。

若用户明确说「直接给答案」「考前速记」「别提问」，可以跳过提示分层。
